# Build vs Buy Decisions — Batch 01

## Build
These are strategic differentiators and should be owned in-platform:
- brand memory / tenant-isolated retrieval and knowledge layer
- strategy generation and board-grade presentation generation
- approval engine and maker-checker workflows
- multi-tenant entitlement and role-control model
- commercial governance layer for subscriptions, invoices, contract state, media balance ledgers, audit events
- campaign and content operating workflows
- reporting semantic layer and explainability layer
- managed-services operating workspace
- specialist marketplace orchestration

## Buy / Integrate
These are better integrated than rebuilt:
- payment gateways
- India-compliant eSign
- global eSignature platforms
- transport layers for email/SMS/WhatsApp
- deep search data sources where necessary
- infrastructure primitives such as storage, queueing, observability, and auth providers where justified

## Hybrid
These should be partially built with external dependency support:
- social listening
- attribution and warehouse analytics
- experimentation statistical tooling
- commerce feed intelligence
- video rendering / heavy media compute
- fraud, KYC, and sanctions tooling where needed

## Why this split is correct
The differentiator is not “we also have another email sender” or “we also have another payment gateway.”
The differentiator is:
- governed execution,
- multi-tenant brand intelligence,
- explainable AI-led growth workflows,
- commercial and operational truth in one surface.

## Explicit no-go choices
Do not build from scratch in v1:
- a regulated wallet/PPI equivalent,
- a proprietary eSign trust framework,
- a full Semrush/Ahrefs-scale search-data network,
- a fully independent ad-network bidding stack,
- an unrestricted autonomous media-spend engine.
