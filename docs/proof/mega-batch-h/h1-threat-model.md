2. Unauthorized action execution
3. Weak lifecycle handling for retained or generated data
4. Missing audit evidence for AI-assisted operations

## Trust Boundaries

- Tenant and workspace boundary
- Governed record and policy source boundary
- Action execution boundary
- Audit event boundary
